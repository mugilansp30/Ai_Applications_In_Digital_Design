# AI Applications in Digital Design

A collection of 10 AI-based digital design experiments implemented using Python and Google Colab.

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Experiments
1. AI-Based Logic Mapping
2. Automation of Synthesis Flow Using AI Search
3. Timing Optimization Using Reinforcement Learning
4. Area and Performance Optimization Using Genetic Algorithm
5. Logic Synthesis Optimization Using Genetic Algorithm
6. Power Consumption Prediction Using Machine Learning
7. Design Fault Detection Using AI Classification
8. AI-Assisted Formal Verification
9. AI-Guided HLS Parameter Tuning
10. AI-Based Test Vector Generation for DfT
